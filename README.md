## ПР2. Ответы на контрольные вопросы

1. Потому что double хранит числа с небольшой погрешностью, например 0.1 + 0.2 даёт 0.30000000000000004, а не ровно 0.3. Для денег это не подходит, а decimal считает точно

2. Значение «переворачивается» и начинает считаться с минимума. Например, если к byte со значением 255 прибавить 1, получится 0

3. В Python переменная может менять тип как угодно. В C# при var тип не указывается вручную, его сам определяет компилятор при сборке, и дальше он уже не меняется

4. Всегда string, даже если пользователь ввёл число

5. Если в int.Parse ввести буквы, программа выдаст ошибку и вылетит. А int.TryParse не падает, а просто возвращает false

6. false значит, что строку не получилось превратить в число. При этом в переменную out запишется 0

7. Когда пользователь сам вводит данные, например возраст, он может случайно написать буквы. С TryParse программа в таком случае не упадёт
